# Task 16 — Selecting Rows and Columns with loc and iloc

## Description
This project explains how to select rows, columns, individual cells, ranges, and conditionally filtered records from a Pandas DataFrame using `loc[]` and `iloc[]`.

## Objective
Develop accurate DataFrame selection skills.

## Core Rule
- `loc[]` = label-based selection
- `iloc[]` = integer-position-based selection

## Topics Covered
1. DataFrame index and column labels
2. `loc[]` syntax
3. Single-row selection
4. Multiple-row selection
5. Single-column selection
6. Multiple-column selection
7. Row and column combinations
8. Label slicing
9. Conditional selection
10. Multiple conditions
11. `iloc[]` syntax
12. Position-based row selection
13. Position-based column selection
14. Positional slicing
15. Negative positions
16. Step slicing
17. `loc` vs `iloc`
18. Common mistakes
19. Best practices
20. Practical student-performance analysis
